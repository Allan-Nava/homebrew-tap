# CLAUDE.md — homebrew-tap

**homebrew-tap** (`github.com/Allan-Nava/homebrew-tap`): il tap Homebrew dei progetti Allan-Nava, usato come `brew tap Allan-Nava/tap` (Homebrew taglia il prefisso `homebrew-`). È un repo di **distribuzione**, non di sviluppo: contiene solo cask/formula generati, zero codice, zero build. Oggi un solo cask, `Casks/checkfleet.rb`, per la CLI [checkfleet](https://github.com/Allan-Nava/checkfleet).

## Regole di lavoro (SEMPRE)

- **I file in `Casks/` sono generati da GoReleaser e NON si editano a mano** — l'header lo dice: `# This file was generated by GoReleaser. DO NOT EDIT.` Ogni tag `v*` su checkfleet rigenera il cask e committa qui (`Brew cask update for checkfleet version vX.Y.Z`) sovrascrivendo tutto. Un fix va fatto **upstream**, in `.goreleaser.yaml` → `homebrew_casks`, e poi rilasciato con un tag.
- **Nessun bump manuale di `version`/`sha256`**: i 4 checksum (darwin/linux × amd64/arm64) li calcola la CI sui tarball della release. Scriverli a mano = install rotta con `SHA256 mismatch`.
- **MAI `git push`** — lo fa sempre l'utente. MAI `Co-Authored-By` nei commit.
- **Qui non si taggia e non c'è CHANGELOG**: il versioning e la release vivono nel repo del progetto. La history di questo repo è quasi interamente bot: non inquinarla con commit rumorosi.
- **Gate prima di chiudere**, se si tocca un cask/formula o si aggiunge un nuovo progetto al tap: `brew style` + `brew audit --cask --online` verdi, più un `brew reinstall --cask` di prova dal tap locale.
- **Niente segreti**: il token che permette a GoReleaser di pushare qui (`HOMEBREW_TAP_GITHUB_TOKEN`) è un secret della CI di checkfleet e non deve mai comparire in questo repo.
- Il README è l'unica doc user-facing: se cambiano i comandi d'installazione, aggiornarlo.

## Comandi

```bash
brew tap Allan-Nava/tap                  # aggiunge il tap
brew install --cask checkfleet           # install (cask, non formula)
brew upgrade --cask checkfleet
brew uninstall --cask checkfleet
brew style Casks/checkfleet.rb           # lint di stile (rubocop Homebrew)
brew audit --cask --online checkfleet    # url/sha256 raggiungibili e coerenti
brew reinstall --cask checkfleet         # ri-esegue il postflight (quarantine)
brew tap-info --json Allan-Nava/tap      # cosa espone il tap
```

Il tap installato è un clone in `$(brew --repository)/Library/Taps/allan-nava/homebrew-tap`: per provare modifiche non ancora pushate si lavora/checkout lì, altrimenti Homebrew continua a vedere la versione remota.

## Struttura

- `Casks/checkfleet.rb` — cask generato: `version`, blocchi `on_macos`/`on_linux` × `on_intel`/`on_arm` con url+sha256 dei tarball della release GitHub, `binary "checkfleet"`, `livecheck { skip }`, `postflight` che rimuove la quarantine.
- `README.md` — istruzioni d'installazione per gli utenti.
- Niente CI, niente workflow: i commit arrivano dall'esterno (GoReleaser del progetto upstream).

## Trappole note / regole tecniche

- **Il `postflight` con `xattr -dr com.apple.quarantine` è VOLUTO**: i binari non sono firmati né notarizzati, senza quello Gatekeeper blocca l'eseguibile appena installato. Non "sistemarlo" e non rimuoverlo; se va cambiato, si cambia in `hooks.post.install` nel `.goreleaser.yaml` upstream.
- **`livecheck { skip "Auto-generated on release." }` è voluto**: la versione la spinge la release, non un check periodico. Non sostituirlo con un livecheck sui tag.
- **Cask e non formula**: non si compila da sorgente, si scaricano i binari della release. Di conseguenza `brew audit`/`brew style` vanno invocati in modalità cask, e i comandi espliciti vogliono `--cask` (`brew install checkfleet` funziona solo come shorthand).
- **Un commit locale divergente rompe la release upstream**: GoReleaser pusha su questo repo durante la release del progetto; se `main` qui ha commit che conflittano, la release fallisce a metà. Tenere il repo pulito e allineato a `origin/main`.
- Aggiungere un nuovo progetto al tap si fa **dal progetto**: sezione `homebrew_casks` (o `brews`) nel suo `.goreleaser.yaml` con `repository: {owner: Allan-Nava, name: homebrew-tap}` + secret `HOMEBREW_TAP_GITHUB_TOKEN`. Non creando a mano il file qui.
