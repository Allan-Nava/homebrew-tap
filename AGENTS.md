# AGENTS.md — homebrew-tap

**homebrew-tap** (`github.com/Allan-Nava/homebrew-tap`): tap Homebrew dei progetti Allan-Nava. Contiene **solo** cask/formula, nessun codice. Oggi un solo cask: `Casks/checkfleet.rb` (CLI [checkfleet](https://github.com/Allan-Nava/checkfleet)).

Questo file definisce le regole operative per gli agent (Copilot, Claude, altri tool AI) quando lavorano in questo repository.

## Regole di lavoro (SEMPRE)

- **MAI editare a mano i file in `Casks/`**: sono **generati da GoReleaser** (`# This file was generated by GoReleaser. DO NOT EDIT.`) e sovrascritti al prossimo tag upstream. Serve un cambio? Si modifica `.goreleaser.yaml` nel repo del progetto (sezione `homebrew_casks`) e si taggia una release lì.
- **Nessun bump di versione manuale**: `version` + i 4 `sha256` (darwin/linux × amd64/arm64) arrivano dalla CI del progetto. Riscriverli a mano produce checksum sbagliati e install rotte.
- **MAI `git push`**: lo fa sempre l'utente. MAI `Co-Authored-By` nei commit.
- **Niente CHANGELOG/tag qui**: il versioning vive nel repo del progetto. La history di questo repo è quasi tutta bot (`Brew cask update for <tool> version vX.Y.Z`): non inquinarla.
- **Gate prima di chiudere** (se si tocca un cask/formula o si aggiunge un progetto): `brew style` + `brew audit` verdi sul cask, e install di prova dal tap locale.
- **Niente segreti** nel repo: `HOMEBREW_TAP_GITHUB_TOKEN` è un secret nella CI del progetto, non compare mai qui.

## Comandi

```bash
brew tap Allan-Nava/tap                  # aggiunge il tap
brew install --cask checkfleet           # install (è un cask, non una formula)
brew upgrade --cask checkfleet
brew style Casks/checkfleet.rb           # lint stile
brew audit --cask --online checkfleet    # audit (url/sha256 raggiungibili)
brew reinstall --cask checkfleet         # verifica postflight/quarantine
```

Il tap installato in locale è un clone in `$(brew --repository)/Library/Taps/allan-nava/homebrew-tap`: per testare modifiche non pushate, lavorare lì o `brew tap --force` sul path locale.

## Trappole note

- **Il `postflight` con `xattr -dr com.apple.quarantine` è VOLUTO**: i binari non sono firmati/notarizzati, senza quel passo Gatekeeper li blocca. Non rimuoverlo "per pulizia" — e se serve cambiarlo, si cambia negli `hooks.post.install` del `.goreleaser.yaml` upstream.
- **`livecheck { skip "Auto-generated on release." }` è voluto**: la versione la spinge la release, non il livecheck.
- **Cask, non formula**: nessuna compilazione da sorgente, si scaricano i tarball della release. `brew install checkfleet` funziona per shorthand, ma i comandi espliciti vogliono `--cask`.
- Nome repo `homebrew-tap` → si usa come `Allan-Nava/tap` (Homebrew taglia il prefisso `homebrew-`).
- Un commit manuale che entra in conflitto con il commit del bot rompe la release upstream (il push di GoReleaser fallisce): tenere il repo allineato e pulito.
